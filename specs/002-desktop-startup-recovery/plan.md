# 实施计划 · 桌面独立启动与会话接续

使用现有 PowerShell 和 Node.js，沿用同源 HTTP、设备登录和现有历史读取。

- 先从目标 Windows 收集旧部署的可用证据，再核对官方桌面包的版本、可用 IPC 和接续协议。
- 停用旧启动入口的共享启动功能。Bridge 只以显式 `--app-server-url` 连接独立管理的回环 App Server。提供迁移核对和恢复步骤。
- 只有桌面提供可核验的会话归属、账户边界与写入确认时才实现当前版本的桌面写入。兼容性未通过时提供显式桌面历史只读模式，保留草稿并显示可操作的提示。普通 Bridge 模式仍可运行独立任务。
- 把发送后的传输故障与请求提交前的失败区分开。浏览器在核对会话前保持待确认状态。
- 核对官方 SSH 接入条件和旧版共享连接的可复用部分。通过自动化覆盖启动参数、只读边界和发送结果未知，并在实际目标版本上记录验收。
