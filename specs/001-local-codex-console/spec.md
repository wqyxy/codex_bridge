# 功能规范 · 局域网 Codex 控制台

**创建日期** 2026-11-26  
**来源** [Issue #1](https://github.com/wqyxy/codex_bridge/issues/1)

## 用户场景与验收

### US1 · 登录和操作本机任务（P1）

Windows 用户在主机或同一 Wi-Fi 上的手机打开中文界面，使用主机提供的用户名和密码访问本机 Codex。独立验证方式为用同一组凭据登录两台设备，从配置目录发起任务，并从历史打开会话。

1. **AC1** 两种设备均可登录、分页查看历史、接续可写会话和新建会话。网页实时显示回复、命令输出、文件改动和计划进度。运行中可补充指令、停止任务。独立后台遇到会话占用时保留草稿，原客户端释放后可在原会话重试。
2. **AC5** 刷新或短时断网后恢复当前执行进度及待处理事项。
3. **AC6** 未登录设备无法读取会话或发起操作。错误密码无法登录，连续失败会被限速。两台设备同时响应同一审批时只有一次生效。用户可退出当前设备，主机可撤销任一设备。已登录用户可核对当前密码后修改网页密码。保存后旧密码和其他设备的登录失效，发起修改的浏览器保持登录，新密码在服务重启后仍有效。
4. **AC8** 侧栏显示本机项目，并按项目组织历史会话。用户可独立展开或折叠每个项目，打开项目中的旧会话，刷新后仍保留各项目的展开状态。缺少项目归属时按工作目录展示，缺少目录的会话仍可打开。
5. **AC9** 侧栏复用当前 Windows Codex 桌面端的本地项目名称、排列和置顶，置顶栏同时显示本机对话和项目。用户可展开置顶项目。桌面端调整后，网页刷新能反映最新顺序和置顶。
6. **AC10** 会话列表用蓝点标识有未读回复的对话。网页打开并加载相关会话后标记已读。未读状态使用 Codex 的回执，刷新后仍能恢复。
7. **AC11** Bridge 可连接主机回环地址上的共享 App Server。两个客户端连接同一后台时，网页可以在原会话 ID 发送和接收回复。网页重连不关闭共享后台。
8. **AC12** 配置共享启动后，同一 Windows 用户登录时自动启动回环 App Server、Bridge 和桌面端。再次启动会复用已连接的实例。服务沿用原会话目录、网页地址和登录凭据。

### US2 · 提问、审批和计划（P1）

用户可在网页继续交互式任务。独立验证方式为使用同一账号、主机和目录与 Windows Codex App 对照。

1. **AC2** 验证单题、多题、预设选项、自定义答案、提交、取消、自动结束与审批结果。以 Codex 返回的请求与状态为准。
2. **AC3** 验证普通与计划模式、计划进度与转入执行，以及模型、推理强度、速度选项的默认值、联动与生效时机。
   - Windows 主机可用时使用桌面版随附的 App Server 动态读取模型目录。刷新、回到浏览器及重新连接时可更新目录。历史会话当前模型暂不可选时，页面明确标注并继续显示真实的模型标识。

### US3 · 读取账户状态和重连（P2）

用户可确认正在使用的本机 Codex 账户。独立验证方式为保留已登录的浏览器，在主机切换账户后重连。

1. **AC4** 只读显示套餐、额度、重置时间和本机可获取的用量。缺少数据时显示实际原因。
2. **AC7** Codex 账户切换并重连后，原浏览器可直接发起任务，套餐和模型反映当前账户。旧会话无法接续时显示具体原因。

### 边界场景

- 用户名或密码错误。浏览器刷新、暂时离线或设备被撤销。
- 两设备同时操作。任务结束、请求撤销或等待重连期间到达操作。
- 本机版本、模型或账户缺少能力。旧历史仍被另一个进程持有。

## 需求

对话区采用独立的冷灰主题。用户消息与助手回复有清楚的视觉区分。回复展示基本 Markdown，连续的命令和文件改动可集中展开。

- **FR-001** 默认仅本机访问。主机可通过指定局域网 IPv4 使用可信局域网 HTTP。
- **FR-002** 主机初次启动时生成用户名和密码。密码可重复用于网页登录，已登录用户可通过网页修改密码，主机仍可重置密码。设备授权可撤销，独立于 Codex 登录状态。
- **FR-003** 网页只使用主机配置的目录新建会话，历史读取与写入的所有权由 Codex 决定。保留本机 Codex 沙箱和审批设置。
- **FR-004** 中文界面支持小屏和桌面尺寸，并支持 AC1–AC7。
- **FR-005** 凭据由主机 Codex 管理。首版覆盖本机实例和已保存历史。

### 关键实体

- **设备** 持有主机颁发的独立授权，可撤销。
- **会话、轮次与请求** 由 Codex 标识，网页跟踪所属会话、实时状态和待处理操作。

## 成功标准

- **SC-001** 同一主机及手机各完成一次 AC1、AC5。两台设备同时提交同一审批时只有一次生效。
- **SC-002** 同一账户、主机和目录对照完成 AC2、AC3 的所有选项。
- **SC-003** 账户切换后在原浏览器完成一次新任务，并核对 AC4、AC7 的账户信息。

## 假设

- 主机和登录设备位于可信网络。主机本地管理登录、账户切换、付费、目录及设备。
- 首版范围限于本地 Codex。官方云任务和跨设备接力在范围之外。
